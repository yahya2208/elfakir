# El Fakir — تطبيق الفقير

تطبيق تجاري لبيع الخضروات والفواكه والمنتجات الغذائية الطازجة، يركز على **أقل مسافة بين رغبة الزبون وتأكيد طلبه**.

## الحالة الحالية

**المرحلة 0 (بناء شريحة رأسية) جارية** — اعتمد صاحب المشروع الانتقال من التدقيق النظري إلى تنفيذ متجر يعمل.

- `DOCS_ENGINEERING_ANALYSIS.md` / `DOCS_DECISIONS_REPORT.md` — **مرجع تاريخي من المرحلة 1**. **تحذير: مصفوفة حالات الطلب فيهما أقدم من المرجع المعتمد**؛ المرجع الوحيد الآن هو `packages/supabase/migrations/0002_order_status_domain.sql` (10 حالات / 14 انتقالًا)، وأي تعارض يُحسم من ملف الـ migration لا من الوثيقة.
- `packages/supabase/migrations/` — الصلاحيات والمجالات (0001، 0002).
- `packages/supabase/tests/phase0_gates.sql` — أدلة المرحلة 0 تُقرأ من `pg_catalog`.
- **لم يُطبَّق أي SQL بعد**: لا قاعدة، لا جدول، لا صف واحد. التنفيذ على `ef-test` فقط بعد تأكيد هوية المشروع، ولا إنتاج إطلاقًا.

## متطلبات البيئة (لم يتم تفعيلها بعد)

راجع `.env.example` للحصول على قائمة المتغيرات المطلوبة. **لا تضع أسرارًا حقيقية في هذا المستودع.**

## تعليمات العمل (ملزمة)

1. لا تبدأ ببناء صفحات قبل اعتماد Phase 1 من قبل صاحب المشروع.
2. لا تنشئ Migration أو تطبقها على إنتاج دون موافقة.
3. لا تنفذ SQL إنتاجيًا بنفسك.
4. لا تستخدم أي بيانات أو مفاتيح من FOCUS.
5. لا تُنشر نسخة إنتاجية دون موافقة صريحة.

## رخصة

مSpecial للاستخدام الداخلي لمشروع El Fakir فقط.
